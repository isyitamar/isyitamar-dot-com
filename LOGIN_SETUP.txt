ISY ITAMAR — Login setup

1. Firebase Console > Authentication > Sign-in method: enable Google and Email/Password. Enable the password option, not email-link-only sign-in.
2. Authentication > Settings > Authorized domains: add isyitamar.com and www.isyitamar.com if used. Add your hosting preview domain if you test there.
3. Upload all files and folders. Use HTTPS. Google/Firebase sign-in does not work by double-clicking a local HTML file.
4. Open Login at the upper left. Test account registration, sign-out, email/password login, Google login, a reload and closing/reopening the browser. Test Forgot password using your own email.

Pages: login/index.html and register/index.html. Account creation signs the user in. The account screen shows the signed-in name/email, Back to Home and Sign out. Sessions persist on the same origin/browser until signed out or browser data is cleared.

Firebase project: isy-itamar-web. Uses Firebase Authentication only; Google Analytics was not initialized. No database or order storage is added. Browser Firebase configuration is public client configuration, not an admin credential. Authentication alone does not secure future backend data; server/database authorization rules must be configured when adding protected data.

Validated JavaScript syntax, local references and simulated authentication flows. No live sign-in, account creation, reset email, or browser rendering was performed.
